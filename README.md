# anki-idioms

HTML flashcards built from two Anki decks of English idioms in `data/`:

- **English Idioms & Phrases Dictionary**: 4,773 cards (idiom, meaning, example)
- **Most Common 300 Idioms**: 335 cards (meaning, examples, similar phrases, picture, category)

Open `flashcards/index.html` in a browser. Click or press Space to flip, ←/→ to move, 1 = Again, 2 = Know it, S = speak. Progress is saved in the browser.

To regenerate after changing the decks: `python build.py` (the page layout is in `template.html`).
